# Автоматическое распознавание вида модуляции и оценка параметров радиосигналов методами ML

Итоговый проект курса Data Science. По записи радиосигнала (WAV: I/Q или вещественный сигнал) определяются
**вид модуляции** (11 классов) и **параметры сигнала**: отношение сигнал/шум, несущая, ширина полосы,
символьная скорость, коэффициент скругления (roll-off), разнос частот ЧМн.

## Цели и задачи
- **Цель:** построить и обосновать модель, распознающую вид модуляции по коротким фрагментам сигнала в условиях
  шума и искажений канала, и довести её до работающего продукта (CLI, REST API, веб-интерфейс).
- **Задачи:**
  1. изучить открытые датасеты (RadioML 2016.10a, Panoradio HF), найти их дефекты;
  2. написать собственный генератор сигналов с реалистичным каналом и полными метками параметров;
  3. построить baseline на экспертных признаках (кумулянты, признаки Азаз–Нанди, спектральные) со статистическими
     тестами значимости признаков;
  4. обучить нейросети на сырых I/Q (VT-CNN2, ResNet-1D, CNN-LSTM), провести абляции и сравнить модели
     статистическими тестами;
  5. оценивать параметры сигнала: многозадачная нейросеть против классической ЦОС, гибрид;
  6. ансамбли, перенос между датасетами, устойчивость к искажениям, выбор финальной модели;
  7. продукт: ONNX, обработка WAV любого формата, CLI, FastAPI + Docker, Streamlit; сквозная проверка.

## Данные
| Датасет | Что это | Объём | Использование |
|---|---|---|---|
| **RadioML 2016.10a** (DeepSig, CC BY-NC-SA 4.0) | 11 видов модуляции, окна 128 отсчётов I/Q, ОСШ −20…18 дБ | 220 000 окон | сравнение с литературой |
| **synth/v1** — собственный генератор (`src/amc/generator.py`) | те же 11 классов, окна 1024 отсчёта, канал: многолучёвость Рэлея/Райса, доплер, фазовый шум, сдвиг частоты ±0,05 fs, ошибка тактовой частоты; ОСШ −20…20 дБ; **все параметры сигнала в метаданных** | 220 000 окон | основная разработка, оценка параметров |
| **Panoradio HF** | 18 КВ-режимов, канал Ваттерсона | 172 800 окон | EDA (расширение) |

Найденные дефекты RadioML 2016.10a (ноутбук 01): **AM-SSB — чистый шум** при любом ОСШ (спектральная плоскостность
0,564 = шум), AM-DSB — почти немодулированная несущая, WBFM — тон в 95 % примеров. Поэтому метрики приводятся
и без AM-SSB, а для продукта используется свой генератор. Источники и загрузка — `ДАТАСЕТЫ.md`
(RadioML скачивается с зеркала HuggingFace и читается **безопасным** загрузчиком pickle, `src/amc/radioml.py`).

## Основные результаты (тест)
| Модель | RadioML: acc / ОСШ ≥ 0 | Свой датасет (1024): acc / ОСШ ≥ 0 |
|---|---|---|
| LightGBM на 26 признаках (Optuna) | 54,8 % / 83,7 % | 51,4 % / 75,3 % |
| VT-CNN2 (литература) | 50,6 % / 74,8 % | — |
| ResNet-1D | 61,7 % / 91,5 % | 59,4 % / 86,7 % |
| **CNN-LSTM** | **62,0 % / 91,7 %** | **62,9 % / 88,4 %** |
| Stacking (LightGBM + ResNet + CNN-LSTM) | 62,75 % / 92,2 % | 65,1 % / 90,8 % |

- Нейросети значимо лучше признаков (Мак-Немар p < 1e-300, ДИ разности +6,9…+7,6 п.п. на RadioML).
- Аугментации (фаза, сдвиг частоты, инверсия спектра): +1,2 п.п. (p = 6e-12) и устойчивость к искажениям.
- Перенос: модели, обученные на RadioML, на данных своего генератора — 13 % (уровень угадывания); модель своего
  генератора на RadioML — 45 % (73 % при ОСШ ≥ 10 дБ): собственный генератор с реалистичным каналом обоснован.
- Параметры: ЦОС точнее при ОСШ > 0 (ОСШ, несущая, скорость, полоса), сеть — при низком ОСШ и для roll-off и
  разноса ЧМн; гибрид лучше обоих.
- **Продукт** (сквозная проверка, 440 WAV, fs 48 кГц, ОСШ в полосе 0…25 дБ): 75,2 % в целом, 83–90 % при
  ОСШ ≥ 10 дБ в полосе; несущая — медиана ошибки 9 Гц, ОСШ — 1,4 дБ, полоса — 8 %, символьная скорость — 4,6 %
  (каскад: сеть даёт грубую оценку, линия ЦОС уточняет до долей процента).

## Продукт
```
# CLI: файлы и/или папки (рекурсивно *.wav); рядом с файлом пишется <имя>.amc.json
python -m amc.infer запись.wav папка_с_записями
# REST API (Swagger: http://localhost:8000/docs)
uvicorn app.api:app --port 8000
curl -F "file=@запись.wav" http://localhost:8000/analyze
# веб-интерфейс
streamlit run app/streamlit_app.py
# Docker (без torch, только ONNX Runtime)
docker build -t amc . && docker run -p 8000:8000 amc
```
Конвейер (`src/amc/infer.py`): чтение WAV любого формата (PCM 8–32, float, WAVE_EXTENSIBLE, RF64; моно —
вещественный, стерео — I/Q) → поиск сигнала по спектру → перенос в ноль и передискретизация до занятости полосы
≈ 15 % → окна 1024 → многозадачная сеть (ONNX) → поиск масштаба по самосогласованности → агрегация по окнам →
гибрид ЦОС/сеть (пороги выбраны на val) и каскад «сеть → уточнение ЦОС» для скорости → Гц, Бод, дБ.

## Воспроизведение
```
python -m venv .venv
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install -e .
python -m amc.radioml data/radioml/RML2016.10a_dict.pkl data/radioml/rml2016a.npz   # RadioML
python -m amc.generator --out data/synth/v1 --per-class 20000 --seed 2026          # свой датасет (≈ 40 с)
python -m amc.features                                                               # признаки (data/features)
python tools/run_queue.py && python tools/run_queue2.py                              # обучение (≈ 4 ч на RTX 4080)
python tools/export_onnx.py synth_v1_1024_multitask_s2                               # модель продукта
pytest -q && ruff check src app tests tools
```
Эксперименты логируются в MLflow (`mlflow ui --backend-store-uri sqlite:///mlflow.db`). Фиксированные seed'ы,
версии пакетов — `requirements.lock.txt`. Оборудование: RTX 4080 16 ГБ, 32 ГБ ОЗУ, Python 3.14.
